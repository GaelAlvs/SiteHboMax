# 🎬 Site HBO Max

Projeto de réplica da interface da **HBO Max**, desenvolvido como desafio prático do curso da **Digital Innovation One (DIO)**.

O objetivo do projeto foi colocar em prática conceitos fundamentais de desenvolvimento web, criando uma interface responsiva inspirada na plataforma oficial de streaming.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3

## 📱 Responsividade

O projeto foi desenvolvido com foco em responsividade, garantindo uma boa experiência de navegação em diferentes dispositivos:

* 📱 Smartphones
* 📱 Tablets
* 💻 Desktops

## 🎯 Objetivos do Projeto

* Praticar a estruturação de páginas com HTML5.
* Aplicar estilização utilizando CSS3.
* Desenvolver um layout responsivo.
* Reproduzir a interface de uma plataforma de streaming para fins educacionais.

## 📌 Observação

Este projeto foi desenvolvido **exclusivamente para fins de estudo**, sem qualquer vínculo com a HBO Max ou seus proprietários.
